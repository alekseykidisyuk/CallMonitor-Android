CallMonitor Android build 21 — исправление восстановления после перезагрузки

Назначение
Устраняет бесконечное открытие системных настроек при выключенном Wi-Fi.
Общая проверка подключённого Wi-Fi, разблокировки и времени попытки применяется
к событиям экрана, переходам, нажатиям и вводу поиска. Повторные события не создают
новые параллельные цепочки. Неудачная попытка ограничена 45 секундами, затем пауза
5 минут, не более трёх попыток за загрузку телефона. Лимит сохраняется при
перезапуске службы. Без Wi-Fi служба тихо ждёт и не расходует попытки.
Выход из системных настроек после успеха также имеет конечное число действий.

Установка поверх build 20
1. Включите Wi-Fi и подключитесь к своей сети, чтобы остановить старый цикл.
2. Распакуйте весь архив в отдельную папку. Подключите телефон по USB.
3. Запустите INSTALL_UPDATE.cmd. Не звоните во время установки.
4. Откройте CallMonitor. Должна отображаться версия build #21.
Не удаляйте приложение и не очищайте данные. Установщик использует adb install -r.
Повторный ввод токена не нужен. Сохранённая очередь и локальные записи остаются.

Первая проверка на телефоне
Отключите Wi-Fi, перезагрузите телефон и разблокируйте его. Проверьте в течение
минуты, что можно пользоваться главным экраном и приложениями без самопроизвольных
переходов в настройки. Затем включите Wi-Fi и подключитесь к своей сети.
Если до перезагрузки уже была запись в очереди, проверьте её состояние после сети.

Границы проверки
Автоматические проверки и компиляция не заменяют проверку на Redmi/HyperOS.
Эта сборка исправляет поведение восстановления. Возможность восстановить запись
с нуля после перезагрузки только через мобильную сеть здесь не заявляется.
Запись звука и алгоритм отправки build 20 не менялись; метаданные сборки теперь 21.
До подтверждения восстановления рекордера новые звонки могут не записываться.
После исчерпания трёх попыток автоматический UI ждёт следующей перезагрузки;
беспроводную отладку можно включить вручную в системных настройках.
